# مداد

ورشة كود بالعربي. تكتب التعديل اللي تريده، تشوف الفرق، وبعدين البرنامج يكتبه على المشروع. لو الكود الناتج مكسور، الملفات تفضل زي ما هي.

## التشغيل

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/uvicorn midad.app:app --host 127.0.0.1 --port 8000
```

افتح `http://127.0.0.1:8000`.

أول تشغيل يفتح مشروع «آلة حاسبة» جاهز، عشان تجرّب التعديل على شغل موجود. تقدر كمان تعمل مشروع جديد أو تستورد ملفاتك في ملف zip، وبعدين تصدّرها تاني.

## مفتاح النموذج

من «الإعدادات» حط:

- العنوان: `https://api.openai.com/v1` أو أي خدمة متوافقة، مثل `https://openrouter.ai/api/v1`
- اسم النموذج، مثل `gpt-4o-mini`
- المفتاح

المفتاح بيتخزن في `data/settings.json` على الجهاز اللي يشغّل مداد، ومش بيرجع يظهر في الصفحة. من غير مفتاح، وضع التجربة يفهم طلبات محدودة: إضافة طرح أو ضرب للآلة الحاسبة، أو إنشاء صفحة لمشروع فاضي.

متغيرات اختيارية: `OPENAI_API_KEY` و`OPENAI_BASE_URL` و`OPENAI_MODEL`.

## إيه اللي بيحمي المشروع

- المعاينة بتتعرض قبل الكتابة، والتشغيل مش تلقائي.
- تعديل الملف الموجود بيكون بقطعة نص موجودة مرة واحدة، مش بإعادة كتابة الملف كله.
- صياغة Python وJavaScript وJSON بتتفحص قبل الكتابة.
- لو المشروع اتغير بعد المعاينة، التطبيق بيترفض.
- الحذف ما يتمش غير لو الطلب قال الحذف صراحة.
- «تراجع» يرجّع الملفات للي قبل آخر كتابة.
