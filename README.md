# مداد

استوديو بالعربي لبناء المواقع والألعاب وتعديل المشاريع الموجودة. الطلب يظهر كفرق أو صورة قبل أي كتابة. لو الناتج مكسور، الملفات تفضل زي ما هي.

## التشغيل

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/uvicorn midad.app:app --host 127.0.0.1 --port 8000
```

افتح `http://127.0.0.1:8000`.

أول تشغيل يفتح مشروع «آلة حاسبة». تقدر تعمل مشروع جديد أو تستورد zip وتصدّره.

## الأوضاع

- **تعديل**: يغيّر ملف موجود بقطعة نص ظاهرة مرة واحدة.
- **موقع**: في وضع التجربة يبني موقع «بيت النور» تحت `web/`.
- **لعبة**: يبني لعبة «شرارة» تحت `play/`، وفيها أسهم وأزرار ونقاط وصوت.
- **صورة**: رسمة فانوس للتجربة، أو صورة من Gemini لما المفتاح يتوصل.
- **صوت**: مؤثرات تتولد في المتصفح تحت `sound/`.

المعاينة من زر «المعاينة» بعد التطبيق. التشغيل لملفات Python وJavaScript وHTML من زر «شغّل».

## المحركات

من «الإعدادات» سجّل مفتاح كل محرك على الجهاز اللي يشغّل مداد. المفتاح ما يرجعش للصفحة.

- **ChatGPT**: مفتاح OpenAI، والنموذج الافتراضي `gpt-4.1`. العنوان يقبل أي خدمة متوافقة، مثل `https://api.openai.com/v1`.
- **Claude**: مفتاح Anthropic، والنموذج الافتراضي `claude-sonnet-5-5`.
- **Gemini 3.1**: مفتاح Google. النص `gemini-3.1-pro-preview`، والصورة `gemini-3.1-flash-image`. وضع الصورة يستخدم Gemini حتى لو المحرك المختار ChatGPT أو Claude.

متغيرات اختيارية: `OPENAI_API_KEY` و`OPENAI_BASE_URL` و`OPENAI_MODEL` و`ANTHROPIC_API_KEY` و`GEMINI_API_KEY`.

من غير مفاتيح، اختَر «تجربة». الوضع ده يبني القوالب الجاهزة ويعدّل الآلة الحاسبة، ومش بيتصل بالشبكة.

Woosh من Sony AI لتوليد مؤثرات الألعاب رخصته العامة غير تجارية، فمش داخل النسخة اللي تتباع. صوت اللعبة يتولد في المتصفح.

## إيه اللي بيحمي المشروع

- المعاينة بتتعرض قبل الكتابة.
- تعديل الملف الموجود بيكون بقطعة نص موجودة مرة واحدة.
- صياغة Python وJavaScript وJSON بتتفحص قبل الكتابة.
- الصورة الجديدة ما تتكتبش فوق ملف موجود، وحدها خمسة ميجا.
- لو المشروع اتغير بعد المعاينة، التطبيق بيترفض.
- الحذف ما يتمش غير لو الطلب قال الحذف صراحة.
- «تراجع» يرجّع الملفات، بما فيها الصور، للي قبل آخر كتابة.
- مفاتيح التشغيل بتتشال من بيئة البرنامج اللي بيتشغّل.
